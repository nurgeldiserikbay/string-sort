Current build: offline-first

String Sort Privacy

Last updated: September 18, 2026.

String Sort is designed to work offline. The current production-preparation build does not require an account and does not include advertising, analytics, tracking, cloud saves, or a backend service.

Data stored on your device

  • unlocked level number;
  • earned stars;
  • best completion times;
  • sound, haptic, and graphics preferences.

This information is stored locally by the application so your progress and preferences can be restored. Clearing application storage or uninstalling the app may remove it.

Personal information

The current build does not ask for your name, email address, phone number, location, contacts, camera, photos, or files.

Network SDKs

The current build has no advertising, analytics, or tracking SDK. If a future release adds any network SDK, this privacy notice and the Google Play Data safety declaration must be updated before that release is published.

Children

The current game does not intentionally collect personal information from children or adults.

Support

Project support and release information are maintained in the official repository: String Sort on GitHub.
