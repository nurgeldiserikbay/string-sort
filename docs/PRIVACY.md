# Privacy policy draft — String Sort

_Last updated: 2026-10-04_

String Sort is designed to work offline.

## Current application behavior

The current build:
- does not require account registration;
- does not ask for a name, email address, phone number, location, contacts, photos or files;
- does not include analytics, advertising or tracking SDKs;
- does not send gameplay progress to a server;
- stores level progress, stars, best times and local settings on the device using local application storage;
- may use device haptic feedback for gameplay interactions.

Because the current build has no backend, analytics or advertising SDK, gameplay information stays on the device unless the user separately shares device/application data through operating-system features. The game does not upload level progress, timing, hint usage, rope physics data or diagnostics.

## Local data

String Sort stores:
- unlocked level number;
- earned stars;
- best completion times;
- sound preference;
- haptic preference;
- graphics-quality preference;
- optional peg-marker accessibility preference.

This information is used only to restore the player's progress and preferences.

Removing the application or clearing its application storage may remove this local progress.

## Children

The current game does not intentionally collect personal information from children or adults.

## Future SDK changes

If advertising, analytics, cloud saves, crash reporting or any other network SDK is added, this policy and the Google Play Data safety declaration must be reviewed and updated before publishing that build.
